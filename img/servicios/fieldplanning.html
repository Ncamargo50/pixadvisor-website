¿Qué es FieldPlanning?

O que é FieldPlanning?

FieldPlanning es una herramienta de inteligencia artificial desarrollada por Pixadvisor para generar proyectos de línea automáticamente. A partir de datos de altimetría, pendiente, índice pluviométrico y tipo de suelo, genera escenarios optimizados para terrazas, plantación y pulverización.

FieldPlanning é uma ferramenta de inteligência artificial desenvolvida pela Pixadvisor para gerar projetos de linha automaticamente. A partir de dados de altimetria, declividade, índice pluviométrico e tipo de solo, gera cenários otimizados para terraços, plantio e pulverização.
